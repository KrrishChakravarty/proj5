I created two groups (devs, auditors) and three users: alpha (devs), beta (auditors), gama (no groups). /opt/secure/dev_files is owned by root:devs with mode 2770, so only devs can read and write. /opt/secure/audit_logs is owned by root:auditors with mode 750, so only auditors can read, and nobody can write. Tests with sudo -u showed alpha could read and write dev files but not read audit logs. beta could read audit logs but could not write there or access dev files. gama was denied on both folders and has no sudo rights. This applies least privilege through group ownership and permission bits
